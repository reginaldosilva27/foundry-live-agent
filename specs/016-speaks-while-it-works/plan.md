# Plan: The agent speaks while it works — and sounds better doing it

> The HOW. `spec.md` is `clarified` (every open question but the one AC3/AC4 answer by
> observation). Two changes, both small, neither in `backend/` or `frontend/` logic.

## Approach

**The silence is the agent's to fill, so the change is in the agent definition.** Two levers were
available and only one is legal:

| Lever | Verdict |
|---|---|
| Agent instructions (`agent.yaml`) | **Chosen.** One place, both modalities, no code in the BFF. |
| Per-session `instructions` on the Voice Live session | **Impossible** — "not supported with a custom agent" (`docs/REFERENCES.md`, Voice Live how-to). Also would override the agent this repo exists to show. |
| BFF emits a filler `response.create` / synthesizes "one moment" | **Rejected** — that is the app deciding what the agent says. §8, and it would make the demo a lie. |

So: add a short rule to the instructions, re-apply the agent (a new immutable version), and
**verify by recording a live turn** — because an instruction is a request to a model, not a
guarantee, and this repo does not claim behavior it has not observed (§5, §10). If `gpt-5.5`
declines to speak before the call, the finding is written down and the instruction comes back out.

**The voice** is one configuration default moving from the MAI-Voice-2-Flash tier to the HD tier,
chosen by a listening test the user ran on 2026-09-16 — which is the evidence spec 012 explicitly
said it lacked. `azure-standard` already covers HD names, so no code changes: only the default and
the four places that state it (§4).

Worth naming the interaction between the two halves: the HD tier is expected to be *slower* to
first audio than Flash, and the preamble is what covers exactly that gap. They are in the same spec
because they are the same complaint.

| AC8 | The existing suites, run unchanged (`just verify`) | all |

**On AC3/AC4 honesty.** A live capture is the only thing that can prove a model's behavior, and it
may fail. The fixtures are recorded with `ai/scripts/spike.py` (text) and a control-channel capture
(voice), then redacted with `ai/scripts/redact_fixture.py`. **A fixture is never edited to make
these tests pass** — if the preamble does not appear, AC3/AC4 fail, the instruction is reverted, and
the spec records that the model declined.

The voice capture goes over the WebSocket control channel with a text item, the way
`voice-live-tool-call-20260915.jsonl` was taken: it proves the *ordering* — speech before the
function call — without a microphone in CI. That the ordering is audible in a real spoken session
is confirmed by listening, and said to be a listening test rather than dressed up as an assertion.

## Risks / trade-offs

- **The model may not comply.** Instructions bias; they do not compel. `reasoning: detailed` in
  spec 015 is the precedent: `auto` was asked for and the model declined on short legs. Mitigation:
  AC3/AC4 make the failure visible instead of shipping a claim. No fallback is planned — a fake
  preamble is worse than silence.
- **HD latency.** The HD tier is expected to reach first audio more slowly than
  MAI-Voice-2-Flash, which spec 012 chose specifically for responsiveness. That is the user's
  explicit trade, and the preamble partly hides it. `VOICELIVE_VOICE` is the one-line way back, and
  `.env.example` says so.
- **HD region availability.** `docs/REFERENCES.md` records HD voices as region-limited to a list
  that includes `eastus`; this project's resource is in `eastus2`. The 2026-09-15 probe saw
  `pt-BR-Thalita:DragonHDLatestNeural` echoed in `session.updated` there, which is evidence of
  acceptance and **not** of audio. AC7 exists for precisely this gap; if the HD voice is accepted
  but silent, the default goes back and the finding is recorded.
- **Chat gets chattier.** A line of intent before the tool rows costs a few output tokens per turn
  and slightly lengthens short answers. Judged worth it: it is the same information the activity
  panel already shows, in the one channel that had none.
- **Two `response.completed` legs.** A preamble emitted on the first leg means the turn's text now
  spans both legs. The BFF already sums usage and holds `done` (§9 note in `CLAUDE.md`), so nothing
  changes — but AC8 keeps the existing streaming tests in the loop to prove it.
